Как поставить REA и разобрать первую программу

REA (Reverse Engineer Anything) даёт ИИ-агенту инструменты, чтобы заглянуть внутрь готовой программы без исходников. Здесь установка с нуля и первый разбор на учебном приложении.

Владимир Борисов · Borisov Lab · сверено с официальной документацией REA 22 октября 2026, версия rea-agents 6.7.0
Начать установку Репозиторий REA
Коротко

Если нет времени читать всё

1

REA бесплатный проект с открытым кодом (лицензия MIT). Он подключает к Claude Code, Codex, Cursor и другим агентам инструменты обратной разработки через MCP.

2

Нужны Node.js 22.19+ (или 24.11+, 26+) и ИИ-агент. Для первого разбора больше ничего ставить не нужно.

3

Установка одной командой npx rea-agents@latest setup. Она покажет план изменений и спросит разрешения.

4

Первый разбор на учебном приложении Notes от авторов REA: агент найдёт, куда уходит экспорт заметок, и покажет файлы и строки.

5

Разбирайте свои программы и те, что разрешено исследовать. Разбор идёт на вашем компьютере, но результаты видит модель, на которой работает агент.

00 · Что это

Из чего состоит связка

REA появился на GitHub в апреле 2026 года и к 22 октября собрал больше 360 тысяч звёзд. Сам по себе он не нейросеть: он соединяет вашего агента с инструментами, которые умеют читать готовые программы.

Агент

Claude Code, Codex, Cursor, Gemini CLI и другие. Задаёт вопросы, объясняет найденное, пишет код и тесты.

REA

MCP-сервер и навык (skill) для агента. Даёт инструменты разбора и порядок работы: у каждого вывода опора на файл, функцию или вызов.

Ghidra, Hopper, IDA

Движки для глубокого разбора скомпилированных программ (.exe, .app, библиотек). Для JavaScript и .NET они не нужны.

Что можно разбирать

JavaScript и Electron
Модули, связи, обмен сообщениями между частями приложения. На Electron сделаны многие настольные программы. Ставить ничего не нужно.
Сайты
Структура страницы, скрипты, сетевые запросы. Нужен Chrome, Chromium или Edge.
.NET
Метаданные и инструкции сборок, только чтение файлов.
Android
APK через JADX и JDK 17+, устройство через adb.
Нативный код
Псевдокод, ассемблер, строки, вызовы. Нужен Ghidra, Hopper или IDA.
Игры
Метаданные Unity IL2CPP, архивы Godot.
Прошивки и трафик
Прошивки через Binwalk или Unblob, сетевые дампы через TShark (на Linux), HAR-файлы из браузера.

На выходе псевдокод, ассемблер и связи между модулями. Исходники с прежними именами и комментариями REA не восстанавливает.

01 · Перед началом

Что понадобится

  • Компьютер с macOS, Windows или Linux. Работайте на том компьютере, где лежат файлы, которые хотите разобрать.
  • Node.js версии 22.19+, 24.11+ или 26+. npm ставится вместе с ним.
  • ИИ-агент. Ниже пример для Claude Code: нужна подписка Claude или API-аккаунт. Подойдут и Codex (вход через аккаунт ChatGPT), Cursor, Windsurf, VS Code с Copilot.
  • Терминал. macOS: ⌘ Пробел, наберите «Терминал», Enter. Windows: меню «Пуск», наберите PowerShell, Enter.

Команды вставляются в терминал. Тексты с пометкой «в чат агента» вставляются в окно разговора с агентом.

1

Проверьте Node.js

Откройте терминал и выполните:

Терминал
node -v
npm -v

Видите v22.19 или новее (подходят и v24.11+, v26+)? Переходите к шагу 2. Если версия старше или терминал пишет «command not found», поставьте Node.js 24 LTS.

macOS

Скачайте установщик Node.js 24 LTS (.pkg) на nodejs.org и пройдите шаги. Если пользуетесь Homebrew:

Терминал
brew install node
Windows
PowerShell
winget install --exact --id OpenJS.NodeJS.LTS

Если спросит про условия, нажмите Y. Закройте PowerShell, откройте заново и проверьте node -v.

Linux
Терминал
curl -fsSL https://fnm.vercel.app/install | bash

Перезапустите терминал и выполните:

Терминал
fnm install 24
fnm use 24
fnm default 24

Пакет nodejs из репозитория дистрибутива часто старше 22.19, проверьте версию.

2

Поставьте агента

Если Claude Code, Codex или Cursor у вас уже есть, пропустите этот шаг.

macOS и Linux
Терминал
curl -fsSL https://claude.ai/install.sh | bash
Windows
PowerShell
irm https://claude.ai/install.ps1 | iex

Перезапустите терминал, создайте рабочую папку и запустите агента в ней:

Терминал
mkdir rea-work
cd rea-work
claude

При первом запуске Claude Code попросит войти в аккаунт. Как поставить Codex, Cursor и других агентов, есть на странице установки REA.

3

Подключите REA

Проще всего попросить об этом самого агента. Скопируйте в его чат:

В чат агента
Установи REA и подключи его к этому агенту командой npx rea-agents@latest setup. Покажи мне план установки на одобрение, потом проверь установку.

Или запустите установку сами в терминале:

Терминал
npx rea-agents@latest setup

Что произойдёт дальше:

  • npm спросит разрешения скачать пакет: введите y и нажмите Enter.
  • REA покажет список агентов. Стрелками выберите свой, пробелом отметьте, Enter для продолжения.
  • Появится план: какие файлы настроек изменятся и куда встанет навык. REA сохраняет резервные копии и ничего не меняет без вашего согласия.
  • Установку Hopper для первого раза можно пропустить.

Агента можно указать сразу:

Терминал
npx rea-agents@latest setup --client claude_code

Другие ID: codex, cursor, gemini_cli, windsurf, vscode, claude_desktop.

Обязательно перезапустите агента

Claude Code, Codex, Gemini CLI: выйдите из сессии и запустите снова. Cursor, Claude Desktop, VS Code: закройте приложение полностью (на Mac ⌘ Q), закрытого окна мало.

4

Проверьте подключение

Терминал
npx -y rea-agents@latest doctor --client claude_code --json

В ответе должно быть "healthy": true. Для другого агента подставьте его ID вместо claude_code. Потом спросите самого агента:

В чат агента
Проверь, что REA подключён, и покажи, какими инструментами REA ты можешь пользоваться.

Агент не видит инструменты? Перезапустите его ещё раз. Если не помогло, повторите установку для своего агента командой setup --client и снова перезапустите.

5

Первый разбор на учебном примере

У авторов REA есть учебное приложение Notes: шесть файлов на Electron и кнопка Export notes. Агент разберёт его код, ничего не устанавливая и не запуская.

В чат агента
Скачай https://rea.tools/examples/notes-example.zip в новую папку example и распакуй. С помощью REA выясни, что происходит, когда я нажимаю Export notes. Покажи, куда записывается notes.csv, какие в нём поля, и нужные файлы и строки.

Если агент не может скачать файл, скачайте архив сами, распакуйте и дайте агенту полный путь к папке notes-example с тем же вопросом.

Что должно получиться

Короткое объяснение со ссылками на файлы и строки: кнопка отправляет сообщение notes:export, главный процесс приложения превращает заметки в CSV и записывает notes.csv в папку «Загрузки». Колонки: id и title.

renderer.js · страница

Кнопка Export notes вызывает notes.exportCsv().

preload.js · мост

Отправляет сообщение notes:export главному процессу.

main.js · обработчик

Вызывает форматтер из csv.js и записывает notes.csv.

Если агент не показал строки кода, попросите его об этом отдельно.

Проверьте агента на прогнозе

Хороший разбор проверяется делом. В CSV колонки разделяются запятой. Что будет, если в заголовке заметки есть запятая и кавычки?

В чат агента
Предскажи, как будет выглядеть CSV для заметки с id 1 и заголовком Hello, "REA". Потом запусти форматтер toCsv из примера через Node.js и покажи прогноз и фактический результат.

Правильный результат:

Вывод
id,title
1,"Hello, ""REA"""

Заголовок остаётся в одном поле в кавычках, каждая кавычка внутри удваивается. Следующий вопрос можно задать в том же чате: «Что будет, если файл не удастся записать? Проследи ошибку до страницы».

6

Ваша первая настоящая задача

Когда учебный пример прошёл, берите свою программу и один конкретный вопрос: одна кнопка, один файл, одно поведение. Шаблон:

В чат агента
Используй REA, чтобы разобраться, как в программе /полный/путь/к/программе устроена функция [название].

Сначала определи тип программы и подходящий способ разбора. Не запускай программу без моего подтверждения.

Раздели ответ на три части: что подтверждено, что предположение, что выяснить не удалось. Для каждого вывода укажи опору: файл, функцию, вызов или наблюдение.

Потом опиши механизм простыми словами и предложи, как сделать похожую функцию в моём проекте, с тестами.

Где взять файлы программы

Код Electron-приложения обычно лежит в файле app.asar.

  • macOS: в Finder откройте «Программы», правый клик по приложению, «Показать содержимое пакета», дальше Contents → Resources.
  • Windows: в папке, куда установлена программа, подпапка resources.
  • Полный путь к файлу или папке проще всего получить, перетащив её в окно терминала. В Windows ещё работает правый клик → «Копировать как путь» (в Windows 10 с зажатым Shift).

Без агента, из терминала

Терминал
npx -y rea-agents@latest analyze-javascript-application /полный/путь/к/app.asar --json

Команда принимает папку распакованного приложения или файл ASAR и возвращает модули, импорты и связи частей Electron с подтверждениями.

02 · Второй уровень

Скомпилированные программы

Для .exe, .app и библиотек REA нужен движок разбора. Ставится он на тот компьютер, где работает REA.

Ghidra · бесплатный

Нужны 64-битный JDK 21+ и Ghidra 12.1.4. macOS и Linux (x64 и arm64), на Windows x64 поддержка экспериментальная. На Mac при установке с нуля нужно собрать нативный декомпилятор (понадобятся Xcode Command Line Tools).

Hopper · коммерческий

macOS 12+ и Linux, у демо-версии ограничения производителя. Установщик REA может поставить Hopper сам, после вашего согласия.

IDA · коммерческий

Подключается к уже установленной IDA по отдельной инструкции.

Проверить, что движок виден REA:

Терминал
npx -y rea-agents@latest doctor --provider ghidra --json

Пути к Ghidra и Java, сборка декомпилятора и настройка IDA подробно описаны на странице установки REA. Лицензии на коммерческие движки нужны законные: REA лицензий не выдаёт. Взломанные копии авторы прямо запрещают.

03 · Безопасность и право

Что важно знать заранее

Что уходит в облако

REA разбирает файлы на вашем компьютере, но результаты получает агент. Если агент работает на облачной модели, найденные строки и фрагменты кода видит её провайдер. Закрытый код и данные клиентов без согласования не разбирайте.

Чтение и запуск

Статический разбор только читает файлы. Некоторые режимы запускают программу с правами вашего пользователя. Просите агента не запускать исследуемую программу без подтверждения: эта строка уже есть в шаблоне выше.

Только официальные источники

Ставьте REA из github.com/morluto/rea, с rea.tools или из npm-пакета rea-agents. Авторы предупреждают: похожее название репозитория или скопированный README ничего не гарантируют.

Что можно по закону

Авторы REA называют законные цели: обучение, совместимость, сохранение старых программ, разбор своего софта или того, что вам разрешили исследовать.

В России действует статья 1280 ГК РФ. Законный владелец копии программы может изучать её работу, чтобы понять заложенные идеи и принципы. Декомпилировать можно только ради совместимости со своей программой, и полученное нельзя использовать, чтобы сделать существенно схожую программу.

Лицензионное соглашение программы может добавлять ограничения. Для коммерческих задач сверьтесь с юристом.

04 · Обслуживание

Обновить и удалить

REA обновляется часто, в новых версиях много исправлений. Если ставили через npx, повторите установку и перезапустите агента:

Терминал
npx rea-agents@latest setup

Если ставили командой npm install --global rea-agents:

Терминал
rea update

Убрать REA из настроек агентов вместе с его навыком:

Терминал
npx -y rea-agents@latest uninstall

Node.js, Hopper, ваши файлы и другие MCP-серверы останутся на месте.

Если что-то не так

  • Агент не видит инструменты REA: перезапустите его полностью и проверьте командой doctor из шага 4.
  • PowerShell пишет «running scripts is disabled on this system»: используйте npx.cmd и npm.cmd вместо npx и npm.
  • macOS просит разрешение на автоматизацию (бывает с Hopper): Системные настройки → Конфиденциальность и безопасность → Автоматизация, разрешите приложению, из которого запускаете REA.
  • Ошибка повторяется: обновите REA, перезапустите агента и повторите задачу. Не помогло: создайте issue в репозитории с версией REA, системой и текстом ошибки.
